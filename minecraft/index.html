02

服务器特色

下面这些功能全部在服务端实现，客户端不装任何 mod 也能用。

连锁挖矿

潜行（Shift）+ 用镐挖一块矿石，整条相连矿脉瞬间清空，时运 / 精准采集都生效。

/trigger ovm.toggle

连锁砍树

潜行 + 用斧砍一块原木，整棵树干自动倒下；不潜行时就是普通挖掘，不影响手感。

/trigger tvm.toggle

树叶自动消失

砍完树自动清理树叶，不再留一树浮空叶子，省得还要爬上去手撸。

进服送指南

首次进服自动收到《生存指南》成书，共 4 页；弄丢了可以重新领取。

/function welcome:book

巨型樱花树

樱花树林里会生成一棵巨型樱花盆景树；坐标在：638 74 113。

背包整理

双击背包里的空格子即可整理，也可以输入指令。原版客户端同样可用。

/invsort sort

经验修复

潜行 + 右键手持的「经验修补」装备，直接用当前经验修复耐久；原版客户端也能用。

性能优化

Krypton / Lithium / FerriteCore 三件套，服务端稳定 20 TPS。

03

客户端安装教程

以 HMCL 启动器为例，跟着截图一步一步来，大约 5 分钟。

1

打开 HMCL，点击「下载」

启动 HMCL 后，点击左侧菜单的 下载，进入版本安装页面。

2

选择 26.3 正式版

在版本列表里找到 26.3（正式版），也就是列表第一条，点击右侧的箭头。

3

安装 Minecraft + Fabric

实例名可以填 26.3-Fabric；Fabric 用默认的 0.20.1，Fabric API 这里先不用勾，其他保持默认，点「安装」。

4

回到首页，点击「实例管理」

等下载和安装完成后，回到启动器首页，点击左侧的 实例管理。

5

打开 mods 文件夹，放入模组

进入实例后点击左侧 模组管理 → 打开文件夹，把下载好的 jar 全部放进去（截图里是 5 个，别忘了再加上 Upgraded Iron Chests）；回到启动器勾选启用，然后启动游戏。

6

添加服务器，连接成功

进入游戏后打开 多人游戏 → 添加服务器，地址填 mc.cakepanit.com:25565，连接成功即可出生在 539, 72, 78。

06

进服前须知

几条容易踩坑的地方，先看一眼能省不少事。

01

版本必须严格一致

服务端是 Java 26.3 + Fabric，没有安装跨版本插件。1.21.x、26.2 客户端都无法连接。

02

箱子 / 背包 / 搬运必须双端同版本

服务器已装 Upgraded Iron Chests 1.5.1、Traveler's Backpack 11.4.3、Carry On 2.12.1；客户端要装同版本，否则箱子 / 背包看不到，搬运也用不了。

03

离线模式，名字即身份

服务器关闭了正版验证。进服前先定好用户名，改名会被当成新玩家，背包与位置不继承。

04

Xaero 传送需要 OP

小地图的路点传送本质是执行 /tp，普通玩家点击无效，正常走路或坐船即可。

为什么显示连接失败 / 版本不兼容？
服务端没有装跨版本插件，客户端必须是 Minecraft Java 26.3。 1.21.x、26.2 等版本都连不上；同时确认地址和端口是 mc.cakepanit.com:25565。
需要正版账号吗？
不需要。服务器关闭了正版验证，离线启动器也能进入。
不装 Mod 能玩吗？
可能不能进服 / 功能不全。服务器装了 Upgraded Iron Chests、Traveler's Backpack、Carry On， 客户端必须装同版本；否则箱子 / 背包异常，搬运用不了。连锁挖矿、连锁砍树、经验修复、背包整理仍由服务端生效； 装 Inventory Sorting 只是多一个排序按钮，装 Xaero 只是为了小地图。
改名字后背包和位置怎么没了？
离线模式下用户名就是身份。进服前先把名字定好， 改名会被服务器当成新玩家，之前的背包和位置不会继承。
